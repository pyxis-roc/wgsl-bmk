Dequantize Benchmark

This benchmark executes the dequantize kernel. Note that the values are populated randomly instead of with realistic values. As such, the output values are probably garbage. However, as this is meant to be used for timing, the actual values are not important. What is important is how long it takes to run. It's worth noting that unlike the matrix multiplication benchmark which has loops, this benchmark has no loops and is just straightline code. As a result, the time it takes to run the benchmark is quite small, and the timing results due to bounds accesses may be overshadowed.

The 'Run' button will execute matmul for 'iteration' times and get the mean time.
